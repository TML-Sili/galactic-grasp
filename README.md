# Galactic Grasp

Galactic Grasp ist ein 2D-Weltraumspiel, das ich gemeinsam mit **Dominik Lanz** im Gymnasium entwickelt habe. Wir haben das Spiel im **Juli 2024 innerhalb eines Monats ohne KI** programmiert.

Das Raumschiff bewegt sich vorwärts und lässt sich drehen, mit Seilen an Ankerpunkten festhalten und mit Schüssen gegen Gegner verteidigen. Ziel ist es, möglichst lange zu überleben und Punkte zu sammeln.

## Steuerung

| Aktion | Taste |
| --- | --- |
| Raumschiff drehen | A / D |
| Linkes / rechtes Seil einsetzen | Pfeiltasten links / rechts |
| Schiessen | W |
| Umkehrmanöver | S |
| Pause | Esc |

## Projekt öffnen

1. Das Repository herunterladen oder klonen.
2. Den Projektordner im Unity Hub mit **Unity 2021.3.2f1** öffnen und die Pakete importieren lassen.
3. Die Szene `Assets/Scripts/Scenes/Hub.unity` öffnen und Play drücken.
